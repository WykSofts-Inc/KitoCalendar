# KitoCalendar

Calendars, date ranges, time slots and day timelines for SwiftUI. Part of the
[Kito](https://github.com/WykSofts-Inc/KitoDevKit) ecosystem.

## Installation

```swift
.package(url: "https://github.com/WykSofts-Inc/KitoCalendar.git", from: "0.1.0")
```
